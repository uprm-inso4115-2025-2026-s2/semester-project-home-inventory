== Domain Invariants

A small set of stable domain rules that must remain true across the household inventory domain.

=== Core invariants

* A household has one or more household members while it is active.
* An item instance belongs to exactly one household context.
* An item instance is stored in some location, even if that location is forgotten or described informally.
* A household may contain multiple item instances of the same item type at the same time.
* A household member's participation in a household may change over time.
* Shared-household coordination depends on knowing which items are shared, which are personal, and who may view or manage them.
* If spending is recorded, it remains associated with the household context in which it occurred.
* If an item instance has an expiration date, it may become expired without being consumed.

=== Ownership and participation notes

#Ownership and responsibility vary by household practice: some inventory items are personal while others are shared. The domain therefore supports both personal and shared responsibility without introducing separate ownership entities. Ownership behavior is represented through household membership, personal/shared item status, and household coordination rules.#
