== Entities

[NOTE]
====
Entity definitions live in <<_terminology>>, which is the single source of truth for domain vocabulary. This section adds only the structural information that the terminology table does not carry: the *attribute schema* associated with each entity. If a term appears below that is not in the terminology table, it must be added there rather than defined locally.

The entities catalogued here are exercised by scenario traces in <<_terminology_walkthroughs>>; see that section for the gaps each entity surfaced when used in a real domain scenario.
====

=== Entity attribute schemas

The following table lists the key attributes associated with each domain entity. For the meaning of each entity, see the corresponding row in <<_terminology>>.

[cols="2,4",options="header"]
|===
|Entity (defined in <<_terminology>>)
|Key attributes

|Household
|name (optional label), members, locations, inventory (reality), optional budgets

|Household member
|name/identifier (domain-level), household reference, informal role

|Location
|name/label, optional purpose

|Item type
|name, optional category, optional brand/size/variant, optional barcode

|Item instance (package)
|item type reference, location reference, ownership status (personal/shared), quantity/availability, optional purchase date, optional expiration date, optional notes

|Inventory (reality)
|household reference, item instances

|Tracked inventory record
|artifact type (note/chat/list/memory), item reference (explicit or implicit), last-updated (if recorded)

|Restock list / planner
|entries (item types), reason (low/out/expired), optional responsibility marker, status (active/deferred)

|Notification record
|type (low/out/near-expiry/expired/budget), target (item type/instance or budget), created time, read/unread, dismissed/deferred

|Spending entry
|amount, date/time, payer (household member), scope (shared/personal), optional item type reference, category, notes, transaction type (purchase/refund/adjustment)

|Spending category
|name, optional description

|Budget
|scope (household/category), limit amount, cycle (period), thresholds (warning levels), visibility rules

|Budget status (derived)
|spent-to-date, remaining, percent used, threshold-crossed flags

|Invitation
|sender, recipient, target household, status, expiration timestamp

|Membership
|household reference, participant reference, role, membership state
|===
