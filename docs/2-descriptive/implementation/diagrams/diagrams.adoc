==== Add Item to Inventory
image::Add Item to Inventory.png[]

Shows the workflow for adding a new inventory item using barcode scanning or manual entry fallback. The diagram includes product lookup, validation, saving the item to Supabase, and updating the inventory list through realtime synchronization.

image::Search or Filter Inventory Item.png[]

Shows how a household member searches or filters inventory items using criteria such as item name, category, location, ownership, stock status, or expiration status. The diagram includes the inventory UI, Cubit state management, and database queries.

image::Generate Inventory Report.png[]

Shows the workflow for generating an inventory stock report and exporting it as a PDF. The diagram includes retrieving inventory data, generating report summaries, and saving the PDF file for viewing or sharing.
